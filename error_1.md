## 2.1.6. Грид популярных точек маршрута

| Наиме-<br />нование поля | Тип | Формат | Обязательность | Активность поля на экране | По умолчанию | Логика работы поля | Действия на форме |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **Кнопка выбора варианта отображения** | Кнопка | Иконка `fa-ellipsis-h` | Да | Всегда в строке режимов отображения рядом с «События» и «Маршруты» | Активна для режима «Популярные точки маршрута» | Открывает меню дополнительных вариантов отображения результатов поиска. | При клике раскрывает/скрывает меню вариантов отображения. |
| **Меню вариантов отображения** | Выпадающее меню | Список пунктов | Да | После клика по кнопке `fa-ellipsis-h` | Скрыто | Содержит дополнительные варианты отображения результатов. В текущей версии отображается один пункт: «Популярные точки маршрута». | Закрывается при выборе пункта или клике вне меню. |
| **Пункт меню «Популярные точки маршрута»** | Пункт меню | Иконка `fa-map-location-dot` + текст | Да | Только в раскрытом меню вариантов отображения | Выбран | Переводит боковую панель и карту в режим отображения популярных точек маршрута ТС. | При клике открывает блок «Популярные точки маршрута». |
| **Заголовок блока «Популярные точки маршрута»** | Текстовая строка | Иконка `fa-map-location-dot` + строка | Да | Только в режиме «Популярные точки маршрута» | «Популярные точки маршрута» | Обозначает список точек маршрута, через которые ТС проходило чаще всего. | – |
| **Подзаголовок поиска с номером ТС** | Текстовая строка | Количество проездов + количество популярных точек + `ТС ГРЗ` | Да | Всегда в заголовке боковой панели | `47 проездов • 5 популярных точек • ТС А123ВС177` | Показывает контекст текущего результата: количество проездов, количество найденных популярных точек и государственный регистрационный знак ТС, по которому выполнен поиск. | – |
| **Список популярных точек** | Контейнер | Вертикальный список карточек | Да | Только в режиме «Популярные точки маршрута» | Сортировка по убыванию числа проездов | Отображает популярные точки маршрута, найденные по результатам поиска ТС. Каждая точка представлена отдельной раскрывающейся строкой. | – |
| **Карточка популярной точки** | Контейнер | Блок с номером, адресом, районом и счётчиком | Да | Только в режиме «Популярные точки маршрута» | Первая точка активна и раскрыта | Представляет одну популярную точку маршрута. При выборе точка подсвечивается в списке и на карте. | При клике раскрывает список дат-времени проездов по выбранной точке и центрирует карту на маркере точки. |
| **Порядковый номер точки** | Текстовая строка | Целое число | Да | В каждой карточке популярной точки | Номер в отсортированном списке, начиная с `1` | Показывает место точки в рейтинге популярности. Рейтинг строится по убыванию количества проездов. | – |
| **Адрес точки** | Текстовая строка | Адрес | Да | В каждой карточке популярной точки | Адрес точки из данных маршрута | Отображает наименование точки не координатами, а человекочитаемым адресом, например «Московское шоссе, 18-й километр». | – |
| **Район точки** | Текстовая строка | Строка | Нет | В каждой карточке популярной точки | Район из данных точки | Уточняет территориальную принадлежность точки: район, зона или другой адресный контекст. | – |
| **Счётчик проездов по точке** | Текстовая строка | Число | Да | В каждой карточке популярной точки | Количество проездов через точку | Показывает количество фиксаций ТС в выбранной точке. Используется для сортировки списка и визуального ранжирования маркеров на карте. | – |
| **Раскрывающийся список проездов по точке** | Контейнер | Список строк даты-времени | Нет | Только для активной раскрытой карточки точки | Для первой точки открыт | Отображает фиксации ТС в выбранной популярной точке. В строках выводится только дата-время проезда. | Раскрывается при клике по карточке точки. |
| **Строка даты-времени проезда** | Текстовая строка | `ГГГГ-ММ-ДД ЧЧ:ММ:СС` | Да | В раскрытой карточке точки | Значение времени фиксации из данных проезда | Показывает конкретный момент фиксации ТС в популярной точке. Дополнительные сведения о маршруте в строке не отображаются. | – |
| **Маркер популярной точки на карте** | Маркер | Круглый маркер с числом | Да | Только в режиме «Популярные точки маршрута» | Отображаются все популярные точки | Показывает положение популярной точки на карте. Число внутри маркера соответствует количеству проездов через точку. Цвет маркера зависит от уровня концентрации проездов. | При клике выбирает точку в списке и раскрывает её даты-времени. |
| **Красный маркер точки** | Маркер | Красный круглый маркер | Да | На карте для точек высокой концентрации | Для точек с высоким числом проездов | Обозначает популярную точку с высокой концентрацией проездов. | – |
| **Синий маркер точки** | Маркер | Синий круглый маркер | Да | На карте для остальных популярных точек | Для точек без признака высокой концентрации | Обозначает популярную точку без повышенного уровня концентрации. | – |
| **Легенда карты** | Контейнер | Заголовок «Легенда» + строки условных обозначений | Да | Всегда на карте в режиме «Популярные точки маршрута» | Отображается в левом нижнем углу карты | Расшифровывает цвета маркеров популярных точек. В легенде отображаются только красная и синяя иконки. | – |
| **Строка легенды «Высокая концентрация проездов»** | Текстовая строка | Красный индикатор + текст | Да | В легенде карты | — | Объясняет значение красного маркера популярной точки. | – |
| **Строка легенды «Остальные точки маршрута»** | Текстовая строка | Синий индикатор + текст | Да | В легенде карты | — | Объясняет значение синего маркера популярной точки. | – |
