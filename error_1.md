## 2.1.4. Грид результатов поиска (маршруты)

| Наиме-<br />нование поля | Тип | Формат | Обязательность | Активность поля на экране | По умолчанию | Логика работы поля | Действия на форме |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **Вкладка «Маршруты»** | Кнопка-вкладка | Текст + иконка `fa-route` | Да | Всегда в панели результатов | Не активна, если открыт режим «События» | Переключает боковую панель из списка событий в представление маршрутов ТС. Используется для аналитического слоя «Маршруты». | При клике открывается грид маршрутов; на карте отображается маршрут, выбранный по умолчанию. |
| **Служебная панель группировки** | Текстовая строка | Иконка `fa-layer-group` + строка | Да | Только в режиме «Маршруты» | «Сгруппировано по маршрутам» | Сообщает пользователю, что найденные проезды сгруппированы в маршруты движения ТС. | – |
| **Подсказка состояния раскрытия** | Текстовая строка | Строка | Нет | Только в режиме «Маршруты» | «первый раскрыт» | Отображает правило начального состояния списка: первая карточка маршрута раскрыта после перехода в режим. | – |
| **Карточка маршрута** | Контейнер | Блок с номером, заголовком, статистикой и списком точек | Да | Только в режиме «Маршруты» | Первая карточка активна и раскрыта | Представляет один восстановленный маршрут ТС. Сортировка маршрутов: по убыванию даты и времени начала маршрута. | При клике по заголовку карточка раскрывается/сворачивается; маршрут подсвечивается и перестраивается на карте. |
| **Порядковый номер маршрута** | Текстовая строка | Целое число | Да | Только в режиме «Маршруты» | Номер в отсортированном списке, начиная с `1` | Визуально идентифицирует маршрут в списке и соответствует порядку отображения маршрутов. | – |
| **Заголовок маршрута** | Текстовая строка | `ГРЗ · марка модель` | Да | Только в режиме «Маршруты» | Данные ТС из сработок маршрута | Показывает основной идентификатор маршрута. Если марка или модель не определены, отображается только известная часть данных ТС. | – |
| **Счётчик точек маршрута** | Текстовая строка | Число + слово «точка» / «точки» / «точек» | Да | Только в режиме «Маршруты» | Количество сработок, включённых в маршрут | Отображает количество точек фиксации в маршруте. Склонение зависит от числа. | – |
| **Дата маршрута** | Текстовая строка | `Д ММММ` | Да | Только в режиме «Маршруты» | Дата первой точки маршрута | Показывает календарную дату маршрута. Если маршрут переходит через полночь, отображается дата начала маршрута. | – |
| **Временной интервал маршрута** | Текстовая строка | `ЧЧ:ММ - ЧЧ:ММ` | Да | Только в режиме «Маршруты» | Время первой и последней точки маршрута | Показывает период движения ТС внутри маршрута без секунд. | – |
| **Протяжённость маршрута** | Текстовая строка | Число + «км» | Нет | Только в режиме «Маршруты» | Рассчитанная длина маршрута | Отображает примерную длину маршрута по последовательности точек. Если расчёт недоступен, поле не отображается или отображается «—». | – |
| **Иконка раскрытия маршрута** | Иконка | `fa-chevron-down` | Нет | Только в режиме «Маршруты» | Направлена вниз для раскрытой карточки | Визуально показывает состояние карточки маршрута. Для активной раскрытой карточки иконка поворачивается. | При клике по карточке меняет состояние раскрытия. |
| **Список точек маршрута** | Контейнер | Вертикальная временная линия | Нет | Только для раскрытой карточки маршрута | Для первой карточки открыт | Отображает точки фиксации, из которых состоит маршрут. Сортировка точек: по возрастанию времени фиксации. | – |
| **Точка маршрута** | Контейнер | Блок с названием, описанием и временем | Да | Только в раскрытой карточке маршрута | Данные сработки маршрута | Представляет одну точку фиксации ТС в маршруте. Порядок точек соответствует направлению движения. | При клике может открывать карточку сработки (US.IF.10.4), если действие поддержано в реализации. |
| **Наименование точки маршрута** | Текстовая строка | Строка | Да | Только в раскрытой карточке маршрута | Адрес или название места фиксации | Показывает основное место фиксации: адрес, объект, КПП, пост или участок дороги. | – |
| **Описание точки маршрута** | Текстовая строка | Строка | Нет | Только в раскрытой карточке маршрута | Тип точки или дополнительное описание камеры | Уточняет контекст фиксации: «Въезд в город», «Камера перекрёстка», «Контрольная точка» и т. п. | – |
| **Время точки маршрута** | Текстовая строка | `ЧЧ:ММ:СС` | Да | Только в раскрытой карточке маршрута | Значение `datetime` сработки | Показывает точное время фиксации ТС в конкретной точке маршрута. | – |
| **Иконка времени точки** | Иконка | `fa-clock` | Нет | Только в раскрытой карточке маршрута | — | Визуальный маркер для строки времени точки маршрута. | – |
